Auto EDA Report Generator
An automated Python pipeline that turns raw CSV files into standalone HTML data analysis reports (eda_report.html).

Features
Data Profiling: Auto-detects data types, missing values, and IQR outliers.

Visualizations: Generates Seaborn KDE plots and correlation heatmaps.

HTML Dashboard: Exports a clean, responsive summary report.

Quick Start
Bash
pip install pandas seaborn matplotlib

python main.py

Tech Stack
Python • Pandas • Seaborn • Matplotlib • HTML/CSS
